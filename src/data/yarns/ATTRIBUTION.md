# Yarn color data — attribution and provenance

The yarn lines in this folder are generated by `scripts/import-yarns.mjs` from `sources.json`; each line's JSON
carries the same provenance record (`source`, `license`, `attribution`, `provenance`). The licence gate of
DESIGN.md §5.6 applies: a line ships only with a recorded CC BY (or CC0) provenance. Lines from other sources are
added only with written confirmation from the data's maintainer (linked here) or one fetch through a CC BY API with
the source URL, date and licence recorded.
